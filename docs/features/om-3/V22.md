# OM-3 V22 tethering patch (audit entry)

The independently reconstructed OM-3 V22 USB live-view / tethering patch is a
third-party artifact. This repository audits it; it does not redistribute the
patcher binary or produce a flashable package from the audit tools.

## How to run

1. Place stock firmware at
   `firmware_archive/reference/OM-3/1.1/OLY_E_147_1100_0000_0000.BIN`.
2. Extract the kred archive so the manifest is at
   `research/om3_patcher_20260929/extracted/OM-3 patcher/patches/om3_pc_remote_v22.json`.
3. Optionally decode main and supply the analysis-only patched main required by
   the code-space audit (see tool defaults).

```bash
python3 tools/om3_patch_audit.py --out generated/om3-v22-audit
python3 tools/om3_code_space_audit.py --out generated/om3-v22-code-space
```

`om3_patch_audit.py` reconstructs hashes in memory and never writes an
installable update. Narrative summary:
[HISTORICAL_HACKS](../HISTORICAL_HACKS.md) and
[safety/CODE_SPACE.md](../../safety/CODE_SPACE.md). Model-local cave table:
[safety/om-3/CODE_SPACE.md](../../safety/om-3/CODE_SPACE.md).
